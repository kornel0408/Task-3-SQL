# Task 03: SQL for Data Analysis

## Overview

This project was completed as part of the Elevate Labs Data Analytics Internship Program. The objective was to use SQL to extract, manipulate, and analyze data from an Ecommerce database.

The project demonstrates practical SQL skills including database creation, data insertion, filtering, aggregation, joins, subqueries, views, and query optimization techniques.

## Tools Used

- MySQL Workbench
- SQL
- Microsoft Excel

## Dataset

The Ecommerce database consists of multiple related tables:

- Users
- Orders
- Order Items
- Products
- Reviews
- Events

These tables were imported into MySQL and analyzed using SQL queries.

## Tasks Performed

### Database Setup
- Created database and tables
- Defined relationships between tables
- Inserted data into tables

### Sales Analysis
- Calculated total sales revenue
- Measured total orders
- Computed total quantity sold
- Determined average sales value

### Gender & City Analysis
- Analyzed sales by gender
- Compared revenue across cities
- Evaluated order distribution by city
- Identified cities with high cancellation rates
- Calculated average order value by city

### Product Analysis
- Identified top-selling products
- Found highest revenue-generating products
- Analyzed revenue by category
- Evaluated product ratings
- Compared brand performance

### Advanced SQL Concepts
- Aggregate Functions (SUM, AVG, COUNT)
- GROUP BY and ORDER BY
- INNER JOIN and LEFT JOIN
- Subqueries
- Views
- Indexes for query optimization
